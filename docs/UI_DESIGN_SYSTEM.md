# UI system (starter guidance; not a final design approval)

Retain the project's official logo and approved per-module themes when
implementing screens. Place app-wide layout and accessible controls in
`core/widgets`; tokens and module-specific themes in `app/themes`.

For each implemented screen define: A. UI/UX, B. Functional & Business
Rules, C. Non-Functional Requirements. Include loading, empty, success,
denial, error and confirmation states. Never imply real connectivity using
decorative placeholders or dummy data.
